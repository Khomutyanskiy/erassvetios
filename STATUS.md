# eRassvet — что реализовано

Статус проекта на 24.08.2026. iOS-приложение (SwiftUI) для объявлений, бэкенд — Firebase (Firestore, Auth, Storage, Cloud Functions, Cloud Messaging).

## Аутентификация и профиль

- Регистрация и вход через Firebase Auth.
- Профиль пользователя: аватар (загрузка в Storage), отображаемое имя, контакты.
- Экран подтверждения удаления аккаунта.
- Рейтинг продавца: лайк/дизлайк (+1/-1) от других пользователей, защита от повторного голосования и самоголосования, отображается на детальной странице объявления, в свёрнутой карточке объявления и в профиле.

## Объявления (Лента)

- Создание, редактирование, архивация и переиздание объявлений.
- До 5 фото на объявление, загрузка в Firebase Storage.
- Тип сделки: «Предлагаю» / «Требуется» / «Даром».
- Отдельное поле контакта для конкретного объявления (если отличается от профиля).
- Категории объявлений, управляемые администратором.
- Поиск по названию и описанию + фильтр по диапазону цены — единый блок, скрывается/показывается по кнопке-лупе в шапке вместе с фильтрами категорий и типов сделок.
- Сортировка (по дате, по цене).
- Уникальный подсчёт просмотров (на пользователя/устройство, без накрутки).
- Лимиты на количество активных объявлений, автоархивация просроченных.
- Избранное — добавление/удаление, отдельный экран (модалка с кнопкой закрытия), доступен из шапки Ленты.
- Модерация объявлений в админке с переключателем «включена/выключена».
- Жалобы на объявления/пользователей в чате с возможностью блокировки.

## Чаты

- Список чатов и переписка по объявлению («Написать продавцу»).
- Бейдж непрочитанных сообщений на нижнем таб-баре.
- Push-уведомления о новых сообщениях (Cloud Function + FCM).
- Удаление чата.
- Аватары собеседников подтягиваются и кэшируются в самих документах чата.

## Блог

- Публичная лента постов (текст + до 3 фото).
- Создание поста: до 3 фото, у каждого своя загрузка с индивидуальным индикатором (не общий спиннер на всю пачку).
- Редактирование собственного поста: можно поменять текст, удалить отдельное фото (крестик на превью) или добавить новые, старые файлы подчищаются в Storage.
- Удаление собственного поста.
- Модерация постов админом (approve/reject) с переключателем «включена/выключена»; при включённой модерации повторная публикация после редактирования уходит на проверку заново.
- Система лайков: лайк/дизлайк-переключатель на пост, счётчик, защита от повторного лайка тем же пользователем, оптимistic UI.
- Фото в постах показываются слайдером (свайп между несколькими), кэш последних 10 изображений в памяти + анимированная «шимер»-заглушка на время загрузки вместо мигания.

## Рекламная шторка (интерстишл)

- Показывается один раз при запуске, сразу после сплэш-экрана — шторка на 2/3 экрана снизу с затемнением фона.
- Контент (заголовок, текст объявления, картинка, необязательная ссылка на сайт/Telegram/Instagram и т.д.) полностью управляется из админки.
- Несколько заготовленных шторок в базе, админ выбирает, какая активна.
- Загрузка изображения шторки идёт в фоне во время сплэш-экрана и после — показ самой шторки не блокируется медленной сетью (таймауты с повторной попыткой), картинка появляется поверх уже открытой шторки с шимер-заглушкой вместо пустого места.
- В форме редактирования — предпросмотр «как увидит пользователь» и возможность удалить картинку.
- Ссылки без схемы (например, «www.site.ru») автоматически нормализуются в https://, чтобы кнопка «Перейти» всегда открывала браузер.

## Административная панель

- Управление пользователями (список, роли).
- Управление категориями объявлений.
- Модерация объявлений (вкл/выкл).
- Модерация блога (вкл/выкл, очередь на approve/reject).
- Управление рекламной шторкой (несколько вариантов, активный, предпросмотр).
- Управление контактами поддержки.
- Статистика по приложению.

## Инфраструктура

- Firebase Auth, Firestore (правила безопасности с проверкой ролей на уровне документов и подколлекций), Storage (правила с проверкой роли через cross-service доступ к Firestore).
- Push-уведомления через Cloud Functions + FCM (сообщения в чатах).
- Splash-экран с анимацией названия приложения.
- Иконка приложения.
- Полностью тёмная тема интерфейса (единый набор цветов/стилей AppTheme).
